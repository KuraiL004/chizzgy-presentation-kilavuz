# Chizzgy × Kılavuz Visual Solutions — Interactive Pitch Showcase

A custom web-based presentation and interactive portfolio built by **Chizzgy** specifically for the upcoming strategic partnership meeting with **Kılavuz Visual Solutions (kilavuz.az)**.

> **Note:** This repository houses a dedicated client pitch experience and is separate from Chizzgy's main agency platform.

---

## 🎯 Purpose
This web application serves as a live, interactive presentation deck designed to showcase:
- Tailored visual production, CGI, and VFX capabilities for Kılavuz.
- Selected case studies and high-impact reels relevant to Kılavuz's brand vision.
- Proposed creative direction and production workflow.

---

## 🛠️ Tech Stack & Deployment
- **Framework:** Next.js / React *(Kullandığınız teknolojiye göre düzenleyebilirsiniz)*
- **Styling:** Tailwind CSS
- **Hosting & CI/CD:** Vercel (Auto-deployed from `main` branch)
